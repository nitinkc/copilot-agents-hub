# [SUBJECT NAME] — State

> **How to use this file:** Make one copy of this file per subject (e.g. `DSA — State.md`,
> `System Design — State.md`, `Spanish — State.md`). Attach it alongside whichever persona
> file you're using (Tutor / Editor / Advisor) at the start of a session. After a session,
> the persona will output a `STATE FILE UPDATE` block — paste the relevant pieces into the
> matching sections below so the next session starts from an accurate picture.
>
> This file is read by all three personas — it's the shared memory between them. Keep it
> factual and evidence-based (what actually happened), not aspirational.

## 3. Existing Exposure / Practice History

  partial credit, awkward performances etc. as **diagnostic evidence**, not just failures.
  Record them here rather than omitting them.

## 4. My Own Self-Assessment (to be verified, not trusted blindly)

- What I can do independently and reliably.
- What I can sometimes do, especially when the shape/pattern is familiar.
- What I consistently struggle with.
- How long I naturally persist on something hard before seeking help.
- My typical reaction after seeing a correct answer/solution/model performance — does it
  feel like "I never knew that" (knowledge gap) or "I should have seen that" (recognition/
  transfer gap)?
- Areas I currently find hardest, in my own words (list them — don't yet diagnose *why*,
  that's the Tutor's job).

## 5. Competency Model (used by all personas)

Use this scale for each topic/skill in your matrix below. Adapt the label wording to the
subject if useful, but keep the underlying levels.

| Level | Meaning |
|---|---|
| 0 — Unknown | Little or no meaningful exposure |
| 1 — Familiar | Recognize the concept, can't reliably use it |
| 2 — Functional | Can handle straightforward, familiar-shaped cases |
| 3 — Pattern Recognition | Recognize when it applies, unprompted |
| 4 — Transfer | Can apply it to unfamiliar-but-related cases |
| 5 — Advanced | Can handle hard variations, combine with other concepts, explain why |
| 6 — Performance Ready | Reliable under realistic pressure, with clear communication |

Also tag each topic's status: **Mastered / Functional / Rusty / Pattern-dependent / Weak /
Unknown** — this is separate from the numeric level and should reflect *recency* and
*reliability*, not just peak ability once demonstrated.
