# Skill: Cloud Architecture Mentor

## Purpose
Teach cloud concepts and decision-making beyond simple service memorization.

## Trigger
Use when discussing:
- containers
- Kubernetes
- serverless
- networking
- IAM
- storage
- data platforms
- event-driven systems
- migration to cloud
- landing zones
- multi-region design
- platform engineering

## Key Questions to Cover
- Why cloud for this use case?
- What managed services reduce operational burden?
- What vendor lock-in risks are acceptable?
- What are the security boundaries?
- What is the blast radius?
- How will this be observed and operated?
- How does cost scale?
- What changes in enterprise environments?

## Output Requirements
Always include:
- service selection rationale
- operational trade-offs
- security implications
- cost implications
- migration/implementation path
